# AD056 - dangling-blank-list-continuation

Tags: `structure`, `conversion`, `docx`, `list`
Severity: error when a heading is captured, otherwise warning.
Fixability: no.
Fix helper: Remove the list style line, blank list item, and continuation marker unless an intentional empty list item is required.

Necessity: A blank ordered-list item followed by a continuation marker can capture the next block. When the next block is a section heading, Asciidoctor renders the heading marker as paragraph text inside the list item instead of creating a section.

Blank list continuations should not capture following content.

Bad:

```asciidoc
[arabic]
.. {blank}
+

== Next section
```

What's wrong: `== Next section` is attached to the empty list item and does not become a section heading.

Good:

```asciidoc
== Next section

Paragraph.
```

Expected: The heading starts outside any list continuation and appears in the document outline.

Rendering rationale: Local Asciidoctor.js rendering confirms that the bad example renders `== Next section` as paragraph text inside an ordered list item.

Implementation note: AD056 matches a narrow conversion-residue sequence: an ordered-list style line, a blank list item, and `+` continuation marker. It skips protected blocks.

# AD026 - missing-xref

Tags: `dependencies`, `xref`
Severity: error
Fixability: no.
Fix helper: Create the referenced anchor/file or fix the xref target.

Necessity: A missing `xref:target[]` or shorthand `<<target>>` target renders as an unresolved reference or broken link. Readers cannot navigate to the intended section, table, figure, or file.


Cross-reference targets should resolve to an anchor or file.

Bad:

```asciidoc
xref:missing-section[]

See <<missing-section>>.
```

Good:

```asciidoc
[[overview]]
== Overview

xref:overview[]

See <<Overview>>.
```

Rationale: unresolved xrefs break navigation and often indicate stale section
IDs after restructuring.

Implementation note: AD026 collects both `xref:target[]` and shorthand
`<<target>>` references. Section titles are accepted through Asciidoctor-style
natural references, generated section IDs such as `_overview`, and explicit IDs
such as `[#overview]`. Non-section content such as images, tables, examples,
list items, and table cells needs an explicit anchor or ID if it is referenced.
Asciidoctor.js can emit `INFO: possible invalid reference` when its logger is
set to `INFO`, but Asciidoctor documents xref validation as limited. AD026 keeps
a project-aware dependency graph so it can validate local includes and file
targets without surfacing every Asciidoctor INFO diagnostic as `AD000`.

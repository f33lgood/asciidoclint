# AD053 - dedication-placement

Tags: core, structure
Severity: warning
Fixability: no.
Fix helper: Use `[dedication]` only on a level-0 or level-1 book section.

What it is used for: A dedication is short book front matter that dedicates the
work to a person, group, or cause. It is usually separate from the technical
content.

Necessity: Asciidoctor documents `dedication` as a book special section.
Asciidoctor.js accepts article, nested, and block-applied dedication markers
silently. AD053 restricts dedication source to documented book front-matter
placement.

Bad:

```adoc
= Article

[dedication]
== Dedication
```

Good:

```adoc
= Book
:doctype: book

[dedication]
== Dedication

For the team.
```

AsciiDoc/Asciidoctor basis: The dedication documentation describes book
placement. Asciidoctor.js records the style in positions outside that contract
without a useful diagnostic, so AD053 reports article, nested, and block-applied
dedication markers.

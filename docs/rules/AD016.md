# AD016 - malformed-figure-caption

Tags: core, image, diagram
Severity: warning
Fixability: no.
Fix helper: Move the caption immediately before the image or diagram and convert it to a `.Title` line without the generated Figure number.

Necessity: A plain `Figure 1:` line adjacent to an image or diagram renders as a paragraph, not as the figure title. The visible caption is separated from the figure semantics.


Figure captions should use AsciiDoc title syntax before the image or diagram.

Bad:

```adoc
Figure 1: Architecture
image::architecture.png[Architecture]
```

What's wrong: `Figure 1: Architecture` is paragraph text. It is not attached to
the image as an AsciiDoc title. The same problem applies when the plain caption
is immediately after the image or adjacent to a diagram block.

Good:

```adoc
.Architecture
image::architecture.png[Architecture]
```

Expected: The title is a `.Title` line before the figure block. Do not include
the generated `Figure 1.` prefix in the title text; Asciidoctor adds the figure
number when rendering titled images and diagrams.

Rendering rationale: a plain `Figure 1:` line renders as a paragraph, not as the
image or diagram title, so the visible caption is detached from the figure
semantics.

Implementation note: AD016 uses the Asciidoctor-derived image and diagram block
model for block positions whenever Asciidoctor exposes the block. It then
source-scans only the immediately adjacent lines for imported `Figure N:`
caption residue. A narrow source scan is necessary because Asciidoctor correctly
parses the residue as an ordinary paragraph, not as failed title syntax.

Limitation: AD016 intentionally does not search across blank lines, prose,
anchors, extra attributes, or other elements to find a nearby `Figure N:`
paragraph. It catches only the common conversion residue where the plain caption
is directly before or directly after an image macro or diagram block. For
diagrams, `Figure N:` immediately before the required diagram style line, such as
`[plantuml]`, is treated as directly before the diagram. The extra source-only
case is `Figure N:` immediately before `image::`, because Asciidoctor can merge
that pair into one paragraph and no image block is available to locate.

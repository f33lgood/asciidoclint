# AD048 - bibliography-placement

Tags: core, structure
Severity: warning
Fixability: no.
Fix helper: Move `[bibliography]` immediately before the bibliography section
heading, or remove it.

What it is used for: A bibliography collects cited or supporting references.
It can be a document-level reference list, or a nested reference list for a
specific section when scoped references are intentional.

Necessity: Asciidoctor documents `bibliography` as a special section style and
allows nested bibliographies for scoped reference lists. Asciidoctor.js also
accepts `[bibliography]` on ordinary blocks, which does not create a
bibliography section. AD048 catches that structural no-op while preserving
documented nested bibliography use.

Bad:

```adoc
= Article

[bibliography]
Reference text.
```

Good:

```adoc
= Article

[bibliography]
== References

* [[[ref]]] Reference.
```

AsciiDoc/Asciidoctor basis: The documented bibliography construct is a section.
Because nested bibliographies are documented, AD048 does not reject nested
bibliography sections. It reports the narrower mismatch where Asciidoctor.js
records the style on a non-section block without creating bibliography
structure.

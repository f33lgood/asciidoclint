# AD011 - image-title

Tags: `core`, `image`
Severity: warning
Fixability: no.
Fix helper: Add a meaningful figure title using `.Title` or `[title="..."]` above the block image, or set `title="..."` in the block image macro. Do not use generic placeholders such as `.Figure` or `.Image`.

Necessity: A block image without a title renders, but it lacks a caption-like label. Readers and generated outputs cannot identify the figure beyond raw alt text or surrounding prose. Generic placeholder titles such as `.Figure` or `.Image` do not identify the image purpose.


Block images should have a title. Asciidoctor image titles are optional, but
when present they render as numbered figure captions unless `figure-caption` is
unset.

Bad:

```asciidoc
image::diagram.png[Overview]
```

Also bad:

```asciidoc
.Figure
image::diagram.png[Overview]
```

Good:

```asciidoc
.Overview details
image::diagram.png[Overview]
```

Also good:

```asciidoc
image::diagram.png[Overview,title="Overview details"]
```

Also good:

```asciidoc
[title="Overview details"]
image::diagram.png[Overview]
```

Rationale: image titles preserve figure intent and make generated output easier
to navigate. Meaningful titles can often be derived from nearby caption text,
section context, image alt text, or the image purpose.

Parser ownership: Asciidoctor.js owns block image parsing and title recognition.
AD011 checks Asciidoctor-derived image blocks and their `title` field, so `.Title`,
`[title="..."]`, and image macro `title="..."` are accepted exactly as
Asciidoctor parses them. Cover images using the `cover-image` role are exempt
because they are cover art rather than numbered figures.

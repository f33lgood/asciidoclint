# AD020 - appendix-section-level

Tags: core, structure
Severity: warning
Fixability: no.
Fix helper: In article documents, change the appendix heading to `==`. Keep `=` only for a book appendix that is intentionally part-like.

Necessity: In article documents, appendices must be level-1 sections. A `[appendix]` block followed by `=` triggers Asciidoctor's native level-0 section error unless the document is `:doctype: book`.


Appendices should be section-level blocks in article documents.

Bad:

```adoc
[appendix]
= API Reference
```

Good:

```adoc
[appendix]
== API Reference

=== Child
```

Also valid for a book appendix that is intentionally adjacent to book parts:

```adoc
:doctype: book

= Book

[appendix]
= API Reference

=== Child
```

AsciiDoc/Asciidoctor basis: Asciidoctor documents article appendices as level-1
sections (`==`). In a book, appendices can be level 1 when adjacent to chapters,
or level 0 when they are part-like in a multipart book.

Rendering rationale: in an article document, `[appendix]` followed by `=`
produces Asciidoctor's native `level 0 sections can only be used when doctype is
book` error. AD020 gives that appendix-specific structure problem a stable rule
ID and repair guidance.

Implementation note: AD020 is a source scanner checked against the document
doctype. It reports only non-book documents with a `[appendix]` line immediately
followed by a level-0 heading. It intentionally allows `:doctype: book` because
level-0 appendices are valid for multipart-book structure.

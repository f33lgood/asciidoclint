# AD020 - appendix-placement

Tags: core, structure
Severity: warning
Fixability: no.
Fix helper: Use `[appendix]` before the appendix section heading. In articles,
use `==`; in books, use `==` for chapter-adjacent appendices or `=` for
part-adjacent appendices.

What it is used for: An appendix contains supplemental material that belongs
after the main body, such as reference tables, implementation notes, or
supporting examples. Asciidoctor can number appendix sections differently from
normal sections.

Necessity: Asciidoctor documents appendices as section styles for articles and
books. In article documents, appendices must be level-1 sections. In book
documents, appendices can be level 1 when adjacent to chapters or level 0 when
adjacent to parts. Appendix subsections start one level below the appendix
title; they do not repeat `[appendix]`. Asciidoctor.js accepts nested appendix
markers silently and can render confusing appendix numbering.


Appendix markers should apply to documented appendix section levels.

Bad:

```adoc
[appendix]
= API Reference
```

What's wrong: An article appendix must be a level-1 section, not a second
document title.

Bad:

```adoc
== Body

[appendix]
=== Nested Appendix
```

What's wrong: `[appendix]` is on a nested subsection. If the whole `== Body`
section is appendix material, move `[appendix]` to that parent section.
Otherwise, remove `[appendix]`.

Bad:

```adoc
[appendix]
----
Block
----
```

What's wrong: `[appendix]` is applied to a block instead of a section heading.

Good:

```adoc
[appendix]
== API Reference

=== Child
```

Also valid for a book appendix that is intentionally adjacent to book parts:

```adoc
:doctype: book

= Book

[appendix]
= API Reference

=== Child
```

AsciiDoc/Asciidoctor basis: Asciidoctor documents article appendices as level-1
sections (`==`). In a book, appendices can be level 1 when adjacent to chapters,
or level 0 when they are part-like in a multipart book. In either case, appendix
subsections start one level below the appendix title and do not repeat the
`appendix` style.

Rendering rationale: in an article document, `[appendix]` followed by `=`
produces Asciidoctor's native `level 0 sections can only be used when doctype is
book` error. AD020 gives that appendix-specific structure problem a stable rule
ID and repair guidance. Asciidoctor.js also accepts `[appendix]` on nested
subsections and ordinary blocks without a useful diagnostic. A nested appendix
marker can produce confusing appendix letters and section numbers, while a
block marker does not create an appendix section at all.

Implementation note: AD020 uses Asciidoctor.js section semantics for rendered
appendix sections, including anchors, includes, and section styles that
Asciidoctor resolves before building the document tree. It reports article
appendices that are not level 1 and book appendices that are nested below level
1. It also checks non-section blocks that receive the `appendix` style, so
`[appendix]` applied to a block is still reported.

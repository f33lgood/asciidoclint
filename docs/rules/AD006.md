# AD006 - included-document-title

Tags: `core`, `include`, `headings`
Severity: error
Fixability: no.
Fix helper: For article parents, add `leveloffset` to the include or change the included file heading to the section level expected by the parent. Keep the level-0 heading only for wrapper-title includes or `doctype=book` part files.

Necessity: A level-0 title inside an included file is expanded into the parent document. In an `article` document that already has a document title, Asciidoctor reports `level 0 sections can only be used when doctype is book`. The documented way to include standalone chapter-like files under an article parent is `leveloffset`, which turns the included document title into the expected section level. A wrapper document may intentionally use its first include to supply the root document title. In a `book` document, included level-0 sections are allowed because they can represent book parts.


Included AsciiDoc files should not introduce an additional level-0 title without level offset.

Bad:

```asciidoc
= Root Title

include::chapter.adoc[]

// chapter.adoc
= Chapter Title
```

What's wrong: The parent article already has `= Root Title`. When
`chapter.adoc` is expanded, `= Chapter Title` becomes another level-0 section in
an article document. Asciidoctor reports this as an error.

Good:

```asciidoc
include::chapter.adoc[leveloffset=+1]

// chapter.adoc
= Chapter Title
```

Expected: The included document can still be authored as a standalone document,
but `leveloffset=+1` makes its level-0 title render as the section level expected
by the parent article.

Also good:

```asciidoc
:doctype: book

= Book Title

include::part-one.adoc[]

// part-one.adoc
= Part One

== Chapter One
```

Expected: In `doctype=book`, additional level-0 sections are valid book parts.
An included file may therefore provide `= Part One` without `leveloffset`.

Also good:

```asciidoc
include::title-page.adoc[]
include::chapter.adoc[]

// title-page.adoc
= Document Title
```

Expected: A wrapper document with no root title may intentionally use its first
include to supply the document title. That included level-0 title is not an
extra article title.

Rationale: `leveloffset` is the explicit Asciidoctor mechanism for including a
standalone chapter-like file under an article parent hierarchy. The first
exception is the first include in a wrapper document, where the included level-0
title is the document title rather than an extra title. The second exception is
`doctype=book`, where additional level-0 sections are valid book parts.

Implementation note: AD006 overlaps intentionally with AD002 and AD000. AD000
captures Asciidoctor's native article error, AD002 checks level-0 title rules
after expansion, and AD006 points to the included title source while documenting
the `leveloffset` fix on the parent include directive and valid exceptions.

Parser ownership: Asciidoctor owns whether the expanded document is valid. AD006
adds include-aware source context by scanning the normalized include graph and
document sections. The source scanner recognizes both documented level-0 title
forms that Asciidoctor accepts, `= Title` and `# Title`, before applying the
wrapper-title and `doctype=book` exceptions.

# AD051 - partintro-placement

Tags: core, structure
Severity: warning
Fixability: no.
Fix helper: Use `[partintro]` on the introductory paragraph or open block before
the first section in a book part.

What it is used for: A part introduction gives context for a book part before
the part's first chapter or section. Unlike most special sections, `partintro`
is documented as a styled block inside a part, not as its own section heading.

Necessity: Asciidoctor documents `partintro` as the introductory block for a
book part, not as a free-standing section style. Asciidoctor.js accepts
`[partintro]` on sections and outside the first-block position in a part. AD051
restricts the marker to the documented part-introduction shape.

Bad:

```adoc
= Book
:doctype: book

= Part One

== Chapter

[partintro]
Intro text.
```

Good:

```adoc
= Book
:doctype: book

= Part One

[partintro]
Intro text.

== Chapter
```

AsciiDoc/Asciidoctor basis: A part introduction belongs after a part heading
and before the first section in that part. Asciidoctor.js records misplaced
`partintro` styles without a useful diagnostic, so AD051 reports them before
the rendered part structure becomes misleading.

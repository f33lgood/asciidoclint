# AD037 - underline-residue

Tags: cleanup, conversion
Severity: warning
Fixability: no.
Fix helper: Remove the three-underscore residue, or convert the intended
underlined text to AsciiDoc emphasis such as `_text_`. Keep four or more
underscores only when they are matching quote block delimiters.

Necessity: Asciidoctor uses four or more underscores as quote block delimiters.
Exactly three underscores are not an AsciiDoc section underline, thematic break,
or quote delimiter. They render as visible residue, often as a broken attempt to
underline converted text.

Parser ownership: Asciidoctor.js is the behavior baseline and does not emit a
diagnostic for three-underscore residue. AD037 uses a narrow source scanner for
exactly `___`, skips protected blocks and table bodies, and deliberately allows
`____` or longer underscore lines because those are valid quote block
delimiters when paired.

Standalone three-underscore underline residue should be removed or converted to
real emphasis.

Bad:

```adoc
Important
___
```

This renders as paragraph content with visible underscore residue, not as an
underline or document structure.

Good:

```adoc
_Important_
```

Allowed quote delimiter:

```adoc
____
Quoted paragraph.
____
```

Rendering rationale: exactly three underscores are not AsciiDoc structure. Four
or more underscores are valid quote block delimiters and are outside this rule.

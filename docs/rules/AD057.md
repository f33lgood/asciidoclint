# AD057 - semantic-anchor-target

Tags: `anchor`, `structure`, `image`, `table`
Severity: warning
Fixability: no.
Fix helper: Move the semantic anchor and title immediately before the intended image, diagram, or table block, or remove/rename the anchor if no such block follows.

Necessity: Semantic anchor prefixes such as `fig-` and `table-` communicate the target block type. If the anchor attaches to a paragraph, heading, or other block, cross references identify the wrong content and generated output can be misleading.

Semantic anchors should attach to the matching block type.

Bad:

```asciidoc
[#fig-overview]
.Overview

Overview details text.
```

What's wrong: The `fig-` anchor and title attach to paragraph text, not a figure.

Good:

```asciidoc
[#fig-overview]
.Overview
image::overview.png[Overview]
```

Expected: The `fig-` anchor and title attach to the image block.

Also good:

```asciidoc
[#table-registers]
.Registers
[cols="1,1"]
|===
| Name | Value
|===
```

Implementation note: AD057 intentionally starts with explicit semantic prefixes: `fig-`, `figure-`, `table-`, and `tbl-`. It does not infer semantics from arbitrary anchor names.

# AD052 - acknowledgments-placement

Tags: core, structure
Severity: warning
Fixability: no.
Fix helper: Use `[acknowledgments]` only on a level-0 or level-1 book section.

What it is used for: An acknowledgments section recognizes contributors,
reviewers, sponsors, or other people and groups who helped produce the book.

Necessity: Asciidoctor documents `acknowledgments` as a book special section.
Asciidoctor.js accepts article, nested, and block-applied acknowledgments
markers silently. AD052 restricts the marker to documented book section levels.

Bad:

```adoc
= Article

[acknowledgments]
== Thanks
```

Good:

```adoc
= Book
:doctype: book

[acknowledgments]
== Acknowledgments

Thanks.
```

AsciiDoc/Asciidoctor basis: The section-style documentation lists
`acknowledgments` for books. Asciidoctor.js can still expose it in article
documents, nested sections, or ordinary blocks. AD052 reports those mismatches
so authoring follows the documented book-special-section model.

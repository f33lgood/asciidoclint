# AD024 - missing-include

Tags: `dependencies`, `include`
Severity: error
Fixability: no.
Fix helper: Create the included file, fix the include target or attribute value, or mark the include optional when it is intentionally absent.

Necessity: A missing include target means source content expected in the rendered document is absent. The output cannot be considered complete.

Description: Include targets should exist after attribute substitution.

Rationale: Asciidoctor reports missing required includes and inserts an unresolved directive into the rendered output. AD024 keeps that dependency failure available as a stable, configurable rule and can report attribute-resolved include paths from the normalized dependency graph.

Bad:

What's wrong: `{chapter-file}` is not defined to an existing include target, so the required content cannot be expanded.

```asciidoc
include::{chapter-file}[]
```

Good:

Expected: The attribute resolves to an existing local include target.

```asciidoc
:chapter-file: chapter.adoc
include::{chapter-file}[]
```

Also good:

Expected: The include is explicitly optional, so an absent file is intentionally dropped rather than treated as a missing required dependency.

```asciidoc
include::optional-chapter.adoc[opts=optional]
```

AsciiDoc/Asciidoctor basis: The include directive is a preprocessor directive.
Asciidoctor documents that a missing required include produces an `include file
not found` diagnostic and an unresolved directive in the output. It also
documents `opts=optional` for includes that should be dropped when absent.

Implementation note: AD024 uses the normalized dependency graph, not a raw file
scanner. The graph applies attribute substitution, resolves relative includes
from the including file, skips external URI targets, and skips missing optional
includes. AD000 may also report Asciidoctor's native missing-include diagnostic;
AD024 provides a stable dependency-specific rule ID and fix helper.

# AD027 - missing-local-link

Tags: `dependencies`, `links`
Severity: error
Fixability: no.
Fix helper: Create the linked file, fix the local link target, or change the target to an xref or URL when that is the intended link type.

Description: Local link targets should resolve to existing files.

Necessity: A missing local `link:` target renders as a broken link to a file that should ship with the document.

Rationale: Asciidoctor documents `link:` as the macro for linking to a relative non-AsciiDoc file. It renders the link target without checking that the local file exists. AD027 fills that project-dependency gap for publishable document trees.

Bad:

What's wrong: `missing.pdf` is a relative local link target, but that file is not present in the document tree.

```asciidoc
link:missing.pdf[Download]
```

Good:

Expected: The linked local file exists.

```asciidoc
link:datasheet.pdf[Download]
```

Also good:

Expected: A fragment on a local HTML target is allowed; AD027 checks the local file path before the `#`.

```asciidoc
link:tools.html#editors[Editors]
```

Also good:

Expected: URL targets are external and are not checked as local files.

```asciidoc
https://example.com/downloads/report.pdf[Download]
```

AsciiDoc/Asciidoctor basis: Asciidoctor documents the `link:` macro as the explicit way to link to a relative non-AsciiDoc file. Relative AsciiDoc documents should use `xref:` instead, which is covered by AD026. Asciidoctor does not define `attachment:` as a core link macro, so AD027 does not treat `attachment:` text as a built-in dependency.

Rendering rationale: Asciidoctor emits a normal `<a href="...">` link for missing local files and does not emit a parser diagnostic. The rendered output is syntactically valid but points readers to a file that is absent from the delivered document set.

Implementation note: AD027 uses the normalized dependency graph built by the tolerant parser. It scans only local `link:` macros, applies attribute substitution, ignores URL/mail targets, and strips `#fragment` or `?query` before checking the local file path. `xref:` targets are intentionally handled by AD026.

# AD001 - heading-level-progression

Tags: `core`, `headings`
Severity: error
Fixability: no.
Fix helper: Add the missing intermediate parent section, or reduce the skipped heading marker so the section advances by only one level from the previous section.

Necessity: Asciidoctor defines section hierarchy as sequential. Its documentation says nested section levels must be sequential, levels cannot be skipped, and skipped nesting is illegal. Asciidoctor still renders the document and reports this as a native warning, but the generated section tree jumps over a parent level. The document outline is not trustworthy for TOCs, navigation, and readers using section hierarchy.


Section headings must not skip levels.

Bad:

```asciidoc
= Title

=== Skipped
```

Good:

```asciidoc
= Title

== Parent

=== Child
```

Rationale: skipped levels usually indicate a broken document hierarchy.

Parser ownership: Asciidoctor owns the section-level grammar and emits the
native `section title out of sequence` warning for both `=` and supported `#`
section title syntax. AD001 wraps that native diagnostic to provide stable
severity, documentation, and fix guidance.

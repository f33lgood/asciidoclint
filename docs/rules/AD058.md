# AD058 - docx-bookmark-hash-residue

Tags: `cleanup`, `conversion`, `docx`
Severity: warning
Fixability: no.
Fix helper: Remove the generated bookmark, `.anchor` role, and `####` marker. Preserve the meaningful text as plain text, a table-cell value, a block title, or a semantic anchor only when it is actually referenced.

Necessity: DOCX-to-AsciiDoc conversion can leave generated bookmark IDs and hash markers in ordinary list items, paragraphs, or table cells. These fragments render as noisy visible text instead of meaningful AsciiDoc structure.

DOCX bookmark/hash residue should be cleaned up.

Bad:

```asciidoc
|[#_Toc142906710 .anchor]####Requirement summary |
```

What's wrong: The generated `_Toc...` bookmark, `.anchor` role, and `####` marker are visible conversion residue inside a table cell.

Good:

```asciidoc
|Requirement summary |
```

Expected: The table cell preserves the meaningful text without generated Word residue.

Implementation note: AD058 complements AD055. AD055 handles anchored DOCX Figure/Table caption residue; AD058 handles other `_Toc`, `_Ref`, and `_Hlk` bookmark/hash residue.

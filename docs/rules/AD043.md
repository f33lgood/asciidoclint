# AD043 - section-title-start-left

Tags: headings, structure
Severity: warning
Fixability: no.
Fix helper: If the line is intended to be a section title, remove the leading indentation. If it is intended as literal example text, put it in an explicit listing or literal block.

Necessity: Asciidoctor recognizes section titles as block starts aligned to the
left margin. An indented line that looks like a section title is valid AsciiDoc
literal content, but it is not a section and will not appear in the document
outline, table of contents, or generated section IDs.

Rationale: This rule catches likely conversion or editing mistakes where a
heading was accidentally indented. It is a warning, not an error, because
indented heading-looking text can be intentional literal example content.

Bad:

What's wrong: the indented lines render as literal text instead of becoming
sections.

```asciidoc
= Title

 == Intended Section

 ## Intended Markdown-Compatible Section

Text.
```

Good:

Expected: section markers start at the left margin, so they become sections in
the rendered document model.

```asciidoc
= Title

== Intended Section

## Intended Markdown-Compatible Section

Text.
```

Rendering rationale: the indented title-looking line is not part of the real
section tree, so generated navigation and downstream rules see a different
structure.

Implementation note: This rule source-scans equal-sign section markers and
Asciidoctor's Markdown-compatible hash section markers. It skips protected
blocks. If the heading-looking line is intentionally literal, prefer an explicit
literal or listing block so the source communicates that intent.

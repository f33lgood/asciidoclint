# AD054 - colophon-placement

Tags: core, structure
Severity: warning
Fixability: no.
Fix helper: Use `[colophon]` only on a level-0 or level-1 book section.

What it is used for: A colophon records production details about a book, such
as toolchain, edition, typography, build process, or publishing notes. It is
usually back matter.

Necessity: Asciidoctor documents `colophon` as a book special section.
Asciidoctor.js accepts article, nested, and block-applied colophon markers
silently. AD054 restricts colophon source to documented book section placement.

Bad:

```adoc
= Article

[colophon]
== Colophon
```

Good:

```adoc
= Book
:doctype: book

[colophon]
== Colophon

Production notes.
```

AsciiDoc/Asciidoctor basis: The colophon documentation describes book
placement. Asciidoctor.js records the style in article documents, nested
sections, and ordinary blocks without a useful diagnostic, so AD054 reports
those documentation-vs-parser mismatches.

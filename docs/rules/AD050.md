# AD050 - index-placement

Tags: core, structure
Severity: warning
Fixability: no.
Fix helper: Use `[index]` before a level-1 index section, or a level-0 index
only when it is adjacent to book parts.

What it is used for: An index is a back-matter lookup section generated from
index terms in the document. It helps readers find where important terms,
concepts, or APIs are discussed.

Necessity: Asciidoctor documents `index` as a special section style for
articles and books. Asciidoctor.js accepts nested or block-applied index
markers silently. AD050 keeps generated-index source aligned with documented
section placement.

Bad:

```adoc
= Article

== Body

[index]
=== Index
```

Good:

```adoc
= Article

[index]
== Index
```

AsciiDoc/Asciidoctor basis: Article indexes are level-1 sections. Book indexes
may be level 1 or level 0 when they are adjacent to parts. Asciidoctor.js can
still mark nested sections or ordinary blocks with the style, so AD050 reports
those parser-accepted mismatches.

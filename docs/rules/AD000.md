# AD000 - asciidoctor-diagnostic

Tags: `core`, `parser`
Severity: mirrors Asciidoctor diagnostic severity
Fixability: no.
Fix helper: Review the rule-specific bad and good examples, then apply the smallest edit that makes the source match the expected AsciiDoc structure.

Necessity: Asciidoctor is the reference renderer for AsciiDoc syntax and
rendering semantics. Diagnostics emitted by Asciidoctor should appear as normal
lint findings with file, line, severity, and message instead of being lost on
stderr.

`AD000` is not a configurable built-in rule. It is the normalized wrapper for
diagnostics reported by the Asciidoctor adapter before `AD###` rules run.

Bad:

```asciidoc
= Title

=== Skipped
```

Expected:

```text
AD000/asciidoctor-diagnostic reports the parser warning from Asciidoctor.
Specific rules such as AD001 may also report a more stable asciidoclint finding.
```

Good:

```asciidoc
= Title

== Parent

=== Child
```

Rationale: parser diagnostics are first-class lint output. `asciidoclint` should
not require users to run Asciidoctor separately to see syntax or rendering
diagnostics that the renderer already knows how to identify.

# AD046 - preface-placement

Tags: core, structure
Severity: warning
Fixability: no.
Fix helper: Use `[preface]` only in book documents. Move a book preface before
the first chapter, move a part preface to the first section in its part, and
remove `[preface]` from nested subsections.

What it is used for: A preface is introductory front matter for a book or book
part. It usually gives context, scope, audience, or reading guidance before the
first normal chapter.

Necessity: Asciidoctor documents `preface` as a book special section. A preface
precedes the first chapter of a book or book part, a preface in a normal book is
a level-1 section, and a part preface must be the first level-1 section in the
part. Asciidoctor.js accepts misplaced or nested prefaces silently, but still
renders them as unnumbered special sections, so a misplaced marker can change
numbering and document semantics without a processor diagnostic.

Preface sections should match documented book placement.

Bad:

```adoc
= Article

[preface]
== Notices
```

What's wrong: `preface` is documented for book documents, not article documents.

Bad:

```adoc
= Book
:doctype: book

== Chapter

[preface]
== Preface
```

What's wrong: The book preface appears after a normal chapter.

Bad:

```adoc
= Book
:doctype: book

== Chapter

[preface]
=== Nested Preface
```

What's wrong: `[preface]` is on a nested subsection. If the whole `== Chapter`
section is front matter, move `[preface]` to that parent section. Otherwise,
remove `[preface]`.

Good:

```adoc
= Book
:doctype: book

[preface]
== Preface

=== Preface Subsection

== Chapter
```

Expected: The book preface appears before the first chapter, and its
subsections do not repeat `[preface]`.

Good:

```adoc
= Book
:doctype: book

= Part One

[preface]
== Part Preface

== Chapter
```

Expected: The part preface is the first section in the part.

AsciiDoc/Asciidoctor basis: Asciidoctor documents the preface style as a book
special section. The preface documentation says a preface precedes the first
chapter of a book or book part, that a preface in a normal book must be a
level-1 section, and that a part preface must be the first section in the part.
Preface subsections start one level below the preface title; they do not repeat
the `preface` style. The section-style documentation lists `preface` for book
documents, while article documents use other special section styles such as
`abstract`. Special-section numbering documentation explains that special
sections are not numbered by default.

Rendering rationale: Asciidoctor.js accepts `[preface]` in article documents,
after normal body/chapter sections, and on nested subsections without logger
diagnostics. The section is still rendered as an unnumbered special section when
section numbering is enabled, which can hide a numbering, level, or
document-order problem.

Implementation note: AD046 uses Asciidoctor.js section semantics for rendered
preface sections, including anchors, includes, and section styles that
Asciidoctor resolves before building the document tree. It reports `[preface]`
outside `:doctype: book`, `[preface]` on nested subsections, book prefaces after
normal book chapters, and part prefaces that are not the first child section in
a part. It also checks non-section blocks that receive the `preface` style.

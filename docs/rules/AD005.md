# AD005 - explicit-document-title

Tags: `core`, `headings`
Severity: info
Fixability: no.
Fix helper: Add an explicit `= Title`, `:doctitle:`, or `:title:` to the root document, or make the wrapper document include a title page as its first include.

Necessity: Asciidoctor says the document header is optional for `article` and `book`, and the document title is optional. A document without a level-0 title still renders, and Asciidoctor may infer fallback title metadata from another source such as the first section. For publishable technical document roots, an explicit document title is still useful because it makes metadata, HTML page titles, and PDF title pages predictable. Wrapper documents may intentionally include a title page as their first include.


Root documents should provide an explicit document title. Accepted explicit
forms are:

- a level-0 document title, such as `= Product Guide`;
- `:doctitle: Product Guide`;
- `:title: Product Guide`;
- a wrapper document whose first included AsciiDoc file supplies the level-0
  document title.

For `doctype=book`, the first level-0 title is the explicit document title.
Later level-0 sections are book parts and are handled separately by AD002.

Bad:

```asciidoc
== Overview

Content.
```

Good:

```asciidoc
= Product Guide

== Overview

Content.
```

Also good:

```asciidoc
:doctitle: Product Guide

== Overview
```

Also good:

```asciidoc
:title: Product Guide

== Overview
```

Also good:

```asciidoc
:doctype: book

= Product Guide

= Part One

== Chapter One
```

Also good:

```asciidoc
include::title-page.adoc[]
include::chapter.adoc[]

// title-page.adoc
= Product Guide
```

Rationale: missing titles make rendered output harder to navigate and can hide
hierarchy mistakes. This is asciidoclint guidance, not an Asciidoctor syntax
error or warning, so it is reported as `info`.

Parser ownership: AD005 uses normalized document attributes and section
recognition for title presence, but the accepted title forms come from
Asciidoctor behavior: level-0 `=` titles, supported level-0 `#` titles,
`:doctitle:`, `:title:`, and wrapper documents whose first include supplies the
level-0 title.

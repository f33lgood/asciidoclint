# AD002 - single-document-title

Tags: `core`, `headings`
Severity: error
Fixability: no.
Fix helper: In article documents, change the extra level-0 heading to the appropriate section level, or change the document to `:doctype: book` only when the extra level-0 headings are intended to be book parts.

Necessity: Asciidoctor documentation says a document can only have multiple level-0 sections when `doctype` is `book`; otherwise, an additional level-0 section violates the section-level rules. Asciidoctor reports this as an error in article documents. In a book document, subsequent level-0 sections represent parts and are allowed.


Article documents should have only one level-0 title.

Bad:

```asciidoc
= Title

= Second Title
```

Good:

```asciidoc
= Title

== Section
```

Also good:

```asciidoc
:doctype: book

= Book

= Part One

== Chapter
```

Rationale: only `book` documents may use additional level-0 sections as parts.
For article documents, the extra level-0 section is an Asciidoctor error and the
document hierarchy is invalid.

Parser ownership: Asciidoctor owns the level-0 section rule and emits the native
`level 0 sections can only be used when doctype is book` error for both `=` and
supported `#` section title syntax. AD002 wraps that diagnostic to provide a
stable rule ID and repair guidance.
